# Embedded webfonts: Reddit Sans / Reddit Mono

Source: official Reddit Sans release v1.013 (https://github.com/reddit/redditsans),
produced for Reddit Inc. by Stephen Hutchings (https://www.s-ings.com/).
Embedded in this repo 2026-11-14 by owner choice for the webui.

Bundled files are the vendor's own `web/full` woff2 builds, unmodified:

- RedditSans-{Regular,SemiBold,Bold} + RedditSans-{Italic,BoldItalic}
- RedditMono-{Regular,SemiBold,Bold} (the mono family ships no italics)

License: SIL Open Font License 1.1 -- full text with the copyright notice in
`OFL.txt`; `FONTLOG.txt` (copied from the release) is the vendor's changelog,
which the release asks to distribute alongside the fonts.

Compliance posture: the binaries are redistributed unmodified, bundled with
the software per OFL condition 2, with the copyright notice and license
standing beside them here. The fonts stay under OFL regardless of this repo's
MIT license (OFL condition 5). No selling of the fonts by themselves, no
modified versions, and no Reserved Font Name obligation exists for this
release (RFN declaration removed in v1.011).
